- `task2-description.png`: Modify furniture with an enabled, edited Description field. The edit was applied through the real view/controller binding and verified on the furniture object.

The PNGs are native macOS window captures of the running Java 8 application and its dialog/menu. They were captured by window ID so unrelated desktop applications are excluded. Java UI-test automation prepared the states shown in the captures. The PDF uses the application's unchanged PDF export pipeline and was rasterized and visually inspected on all four pages.
